# Students-Scientific-Society


# 🤖 СНО Bot & Userbot System

Система для управления участниками и массового пинга по категориям для чата СНО (Студенческого научного общества) в Telegram. Проект состоит из основного бота на **Aiogram 3.x** и юзербота на **Telethon**, которые работают в связке через общую базу данных **SQLite3**.

---

## 🚀 Возможности

- **📁 Управление категориями:** Создание направлений и распределение участников по категориям прямо через удобный интерфейс с инлайн-кнопками в личных сообщениях боту.
- **🔔 Массовый пинг в группе:** Команда `/ping Название категории` в чате группы автоматически находит всех участников направления и отправляет красивое упоминание пачками по 10 человек через скрытые Markdown-ссылки с ID (`[Имя](tg://user?id=...)`).
- **🔍 Гибкое добавление участников:** При добавлении человека в категорию бот интеллектуально распознает:
  - Числовой `user_id` (например, `8037743020`)
  - Спец-ссылки вида `tg://user?id=8037743020`
  - Обычные юзернеймы (`@username`)
- **🔄 Синхронизация в реальном времени:** Юзербот автоматически отслеживает вступления и выходы участников из группы (`ChatAction`), обновляя базу данных «на лету».

---

## 🛠 Стек технологий

- **Python 3.10+**
- **Aiogram 3.x** (для основного бота)
- **Telethon** (для юзербота и работы с событиями чата)
- **SQLite3** (для хранения пользователей, категорий и связей)
